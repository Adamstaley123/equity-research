▸ Methodology & data sources how every number is computed

Sources

Financial statements (revenue, EBITDA, FCF, cash, debt) come from the SEC EDGAR XBRL API — authoritative 10-Q / 10-K filings. Market data (price, shares) from Yahoo Finance. Click any ticker to see each figure's exact source, filing, and formula.

Curated, not screened

Each sector is a hand-picked peer set, not an algorithmic screen. This page is a deterministic render over those committed sector datasets — no live data is fetched when the page is built. Compare companies within a sector; multiples are not directly comparable across different sectors.

TTM & freshness

TTM = the four most recent quarters (or YTD reconstruction for cash-flow items). Every value is checked against the company's latest filing date; anything stale is dropped to N/A with a reason rather than shown.

Enterprise value

EV = Market Cap + Total Debt − Total Cash, computed from components. Pre-computed EV fields are not used (known stale-value issues). Market cap = price × basic shares.

EBITDA

EBITDA = Operating Income + D&A from EDGAR. Where D&A is untagged or unreliable, operating income is used as a proxy and flagged.

Revenue basis

Some names report net revenue (†, only the fee retained) and some gross (full volume, incl. items like excise tax). EV/Revenue is not directly comparable across these.
